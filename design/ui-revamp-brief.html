Four Wheel Steer — UI Revamp

A 2D top-down arcade time-trial racer whose hook is steering the front and rear wheels independently. The gameplay is solid; the menus and HUD are placeholder default-Godot widgets. This brief asks for a cohesive visual identity and a full screen redesign.

The prompt

Copy the block below and give it to Claude in design mode. Everything under it is supporting reference you can paste or attach alongside.

UI REVAMP PROMPT 
You are designing the UI for "Four Wheel Steer," a 2D top-down arcade time-trial
racing game built in Godot 4. The signature mechanic is steering the FRONT and REAR
wheels independently — align both axles to "crab-walk" sideways, oppose them for a
tight pivot. It's a checkpoint circuit racer: 3 laps, medals (gold/silver/bronze),
unlockable levels, best-time/best-lap chasing.

GOAL
Replace the current placeholder UI (default Godot buttons + flat dark background) with
a cohesive, energetic arcade-racer visual identity, and redesign every screen.

DELIVERABLES (in this order)
1. Two or three distinct mood directions (1 paragraph + a color/type sketch each), then
   recommend one. Think: clean modern arcade, retro-90s-racer, or neon synthwave —
   surprise me, but it must feel fast and readable.
2. A design system for the chosen direction:
   - Color tokens (bg, surfaces, primary/secondary accent, success/medal colors,
     text + muted text, danger). Give hex values.
   - Type scale (display / title / heading / body / caption) with one or two web-safe
     or freely-licensed font suggestions.
   - Spacing scale and corner-radius scale.
   - Components with ALL states: Button (default / hover / pressed / disabled / focused),
     Panel/Card, Slider (used for volume AND for the touch steering), Title bar,
     Medal badge, Level tile (locked vs unlocked).
3. High-fidelity mockups of each screen (list below), in BOTH a landscape (desktop) and
   a portrait (mobile) frame, since the game ships on both.
4. The in-race HUD laid out for portrait and landscape (it overlays a moving green
   racetrack, so call out contrast/legibility — outlines, scrims, or chips).
5. A short "Godot mapping" note per component: which Godot Theme primitives implement it
   (StyleBoxFlat fill/border/corner-radius, font + font_size + outline, content margins),
   so an engineer can rebuild it as a Theme resource.

SCREENS TO DESIGN
- Main Menu: title + tagline, buttons [Play] [How to Play] [Settings] [Quit], a volume
  settings panel.
- How to Play: explains the hook with 3 little top-down car diagrams (independent steer /
  opposite = pivot / same = crab walk) + a big "Got it" CTA.
- Level Select: a grid of level tiles. Each unlocked tile shows level name, top speed,
  best time, and earned medal; locked tiles are visibly disabled. Plus a Back button.
- Race HUD: total timer (center top), current lap time, "Lap x/3", level name, best time
  + best lap (best-lap flashes on a new record), a speedometer, a 3-2-1-GO countdown, and
  an off-screen arrow pointing to the next checkpoint gate.
- Results panel: medal headline (colored by medal), Total / Best / Best-lap stats, and
  [Retry] [Next] [Menu].
- Pause panel: PAUSED title, [Resume] [Restart] [Menu], and a volume slider.
- Touch controls (mobile only, overlaying the race): TWO bottom sliders (left = front
  wheels, right = rear wheels) + GAS and REV buttons. Big, thumb-friendly.

HARD CONSTRAINTS
- Must be buildable as a Godot 4 Theme + simple layouts (no fancy shaders required).
  Favor flat fills, solid strokes, simple gradients, vector shapes — it should match the
  game's existing flat/vector art (the cars are simple colored polygons).
- Responsive: desktop opens maximized/landscape, mobile runs PORTRAIT. Layouts must
  anchor/reflow between the two aspect ratios.
- Touch targets >= 48px on mobile.
- HUD text must stay readable over a bright moving background.
- Keep dependencies light: at most one or two font files; prefer vector/procedural over
  large image assets.

BRAND NOTES
- The current accent is a hot yellow-gold (the car's nose and the HUD arrow) on a near-black
  bg, with a blue player car. You may keep, evolve, or replace this — but the result should
  feel kinetic and confident, not corporate.
- The personality is playful precision: the four-wheel-steer trick is clever and satisfying,
  so the UI should feel crisp and a little show-offy without being noisy.

Ask me anything you need before producing the directions.

Game at a glance

What it is

  • 2D top-down arcade racer, Godot 4 (gl_compatibility)
  • Hook: independent front/rear steering → crab-walk & tight pivot
  • 3-lap checkpoint circuits, sim-ish slip-angle handling
  • Gold/silver/bronze medals by total time; levels unlock in sequence
  • 2 levels today (wide intro → tight twisty); progress saved to disk

Platforms & juice

  • Desktop: maximized / landscape
  • Android: portrait, on-screen sliders + GAS/REV
  • Existing feel: skid marks, dust, screen shake, gate pop, countdown beeps
  • All art is flat/vector (cars are simple colored polygons)
  • No external art assets today — SFX are generated procedurally

Current UI — what we're replacing

Every screen is built programmatically in GDScript with stock Godot Button/Label/Panel widgets — no Theme resource, no custom fonts, no styled panels. The look is a flat near-black background with white text and font-size overrides. Functional, but visually placeholder. That's the target of this revamp.
